# Ambition IT

Static website for [ambition-it.co.uk](https://ambition-it.co.uk/).

## Common updates

- Website, add-on, management and hosting prices are configured near the top of `Javascript/pricing.js`.
- The limited-time offer dates, discount and enabled status are configured near the top of `Javascript/main.js`.
- The pricing calculator passes a complete estimate to the contact form through an encoded URL parameter. No personal information is stored in that estimate.

The website is deployed from the `main` branch through GitHub Pages.
